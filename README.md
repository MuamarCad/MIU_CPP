# Задачи по дисциплине Алгоритмизация и методы программирования
Каждая задача в своей папке. Внутри приведено дано и исходные файлы решения.
---
### Требования к оформлению решений
1. Использовать git, при умении. Допускаются флешки
2. Сохраняем файл `.cpp`
3. Оформление задач отдельными функциями, чтобы не множить исходники
4. Функции подписываются комментарием с решением и вызовом решения в `main()`
---
### Запуск в терминале
Выполнение из корня проекта `MIU_CPP/`
```bash
cd task_number
g++ file.cpp -o file_name
./file_name
```
---
### Запуск в VSCode
Требуется установка расширения C/C++ by Microsoft
1. Откройте ваш файл `.cpp` в редакторе (убедитесь, что он активен, то есть вкладка сверху выделена).
2. Посмотрите в правый верхний угол окна редактора (справа от вкладок).
3. Там будет кнопка с иконкой Play (треугольник) и подписью Run C/C++ File (или просто иконка Play).
4. Нажмите на неё.
5. VS Code сам сохранит файл, скомпилирует его и выведет результат в нижний терминал.
